An Airbnb‑like web application built with **Node.js, Express, MongoDB, and EJS templates**.  
It provides a platform to list, explore, and manage rental properties with integrated maps, image storage, and user authentication.

---

# Features
-  **RESTful APIs** for property listings and user actions
-  **EJS templates** for dynamic server‑side rendering
-  **Map integration** to visualize property locations
-  **Cloudinary storage** for image upload & deletion
-  **Authentication system** (login & sign‑up with secure sessions)
-  **MVC architecture** for clean, maintainable code
-  *Responsive design** for desktop and mobile

---

# Tech Stack
- **Frontend:** EJS, Bootstrap/CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Image Storage:** Cloudinary
- **Authentication:** Passport.js / bcrypt
- **Maps:** map integration using leaflet
